Ajustes y seguridad

Protege el acceso y crea copias de seguridad de los datos.

🔐 Bloqueo con clave

La clave bloquea el acceso a la agenda en este dispositivo.

La clave no se guarda en texto visible. Se almacena una verificación criptográfica local.

💾 Copia de seguridad

Exporta pacientes, citas, cirugías, pagos y notas a un archivo cifrado.

Para restaurarla necesitarás la misma clave utilizada al crear la copia.

♻ Restaurar copia

Recupera los datos desde una copia de seguridad de Más Vida.

La restauración reemplaza los datos actuales después de confirmar.

📱 Almacenamiento

Los datos clínicos de esta versión se guardan en el navegador del dispositivo; GitHub Pages solo aloja el código de la app.
